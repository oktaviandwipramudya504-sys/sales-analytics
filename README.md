Sales Analytics - Dashboard Interface

Repositori ini berisi file presentasi utama (`index.html`) untuk **Cyber Sales Analytics Dashboard 2022**. Dashboard ini dirancang dengan estetika modern berbalut tema *Cyberpunk / Dark Mode* menggunakan kombinasi warna gelap, aksen hijau *mint*, *cyan*, dan *teal* untuk menyajikan data metrik penjualan secara interaktif dan scannable.


Fitur Utama Interface

Cyberpunk Neon Aesthetic:** Desain *user interface* (UI) berbasis *dark mode* menggunakan Tailwind CSS, memberikan visual yang premium, bersih, dan nyaman di mata.
3D Particle Background Network:** Implementasi *background* interaktif berbasis HTML5 Canvas dan JavaScript murni (Vanilla JS) yang merender jaringan partikel tiga dimensi bergerak secara *real-time*.
Responsive Metric Cards:** Ringkasan metrik utama (Total Baris Data, Variasi Produk, Total Orderan, dan Total Omzet) yang dilengkapi dengan efek hover dinamis dan *border gradient shine*.
Dynamic Component Analytics:** * Tabel interaktif untuk memetakan **Top 5 Produk Unggulan** lengkap dengan kalkulasi format mata uang dan penanda peringkat (*rank badges*).
    Area visualisasi grafik responsif untuk memuat grafik tren omzet bulanan dan top 10 produk terlaris.
    Panel Metrik Evaluasi Model untuk menampilkan performa kalkulasi data (MAE, $R^2$ Score, Data Latih, dan Data Uji).

Teknologi yang Digunakan

HTML5 & CSS3:** Struktur dokumen semantik dan kustomisasi gaya visual mendalam.
Tailwind CSS:** Framework CSS *utility-first* untuk mempercepat proses *styling* yang responsif dan konsisten.
Vanilla JavaScript:** Menggerakkan mesin rendering partikel 3D pada objek Canvas dan menangani arsitektur *asynchronous fetching* (AJAX) untuk komunikasi data tanpa memuat ulang halaman (*refresh*).
Google Fonts:** Menggunakan *font family* `Inter` untuk keterbacaan data numerik yang tinggi dan `Space Grotesk` untuk penegasan judul berkarakter tekno.
